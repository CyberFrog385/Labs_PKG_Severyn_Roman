# Laba2 — анализатор растровых файлов

Лабораторная работа 2 по инженерной и компьютерной графике.
Приложение обходит каталог или отдельный файл и выводит имя, формат,
размер в пикселях, разрешение с единицами, глубину цвета, число каналов,
способ сжатия и цветовую модель. При глубоком анализе дополнительно
считаются число использованных цветов и энтропия.

Поддерживаются шесть форматов: `bmp`, `png`, `jpg`, `gif`, `tif`, `pcx`
(для JPEG дополнительно принимаются `.jpeg` и `.jpe`, всего девять
расширений). Формат определяется по сигнатуре содержимого, а не по
расширению, поэтому подменённое расширение обнаруживается корректно.

Стек: C++20, FLTK 1.4.5 (только интерфейс и вывод картинки), стандартная
библиотека, CMake 4.3.4 и Ninja. Все заголовки и все кодеки сжатия
реализованы вручную — Deflate, LZW, PackBits, RLE4/RLE8, Хаффман и IDCT.

## Структура репозитория

- `src/core/` — чтение файлов, определение формата, разбор заголовков
  (`parsers/`) и кодеки (`codec/`).
- `src/model/` — формат, запись результата, состояние сканирования.
- `src/io/` — обход каталога и пул потоков.
- `src/controller/` — сканирование, агрегация состояния, выгрузка CSV.
- `src/view/` — окно FLTK: таблица, предпросмотр, панель свойств.
- `task/` — лабораторная папка, исходник отчёта и готовая документация.
- `tests/` — генераторы проверочных файлов и наборы `data/` и `corrupt/`.
- `help/` — заметки по сборке и сверке с Pillow.
- `cmake/` — файл настроек кросс-компиляции для Windows.
- `third_party/fltk-1.4.5/` — вендоренные исходники FLTK.
- `winbuild/` — готовые exe под Windows.

## Сборка и запуск (macOS)

```
cd laba2
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

Графическое приложение: `build/Laba2.app/Contents/MacOS/Laba2`.
Консольный анализатор, который не требует графической библиотеки:

```
cmake --build build --target Laba2Scan
./build/Laba2Scan "task/Для проверки Lab2" --deep
```

Команду нужно запускать из каталога `laba2`: относительные пути
разрешаются относительно текущего каталога, и при запуске из `build/`
приложение молча сообщит о `0` файлах.

## Тесты

```
ctest --test-dir build --output-on-failure
```

Семь проверок: разбор лабораторной папки, вывод в CSV, строгий прогон
сгенерированного корпуса, строгий глубокий прогон, прогон повреждённых
файлов, ненулевой код возврата в строгом режиме и значения счётчиков в
сводке. Все проверки запускают консольный анализатор, поэтому тестируется
ровно тот код, которым пользуется окно.

## Windows

Требуется `brew install mingw-w64`. Кросс-сборка с macOS:

```
cd laba2
cmake -S . -B build-win -G Ninja \
      -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-mingw-w64-x86_64.cmake \
      -DCMAKE_BUILD_TYPE=Release
cmake --build build-win
```

Готовые `Laba2.exe` и `Laba2Scan.exe` уже собраны и лежат в `winbuild/`.
Они слинкованы статически и не требуют сторонних DLL. Подробности в
`winbuild/README.md`.
