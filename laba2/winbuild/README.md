# Windows-сборка

Готовые исполняемые файлы для 64-разрядной Windows собраны на macOS
кросс-компиляцией набором компиляторов MinGW-w64 (GCC 16) и лежат
рядом с этим файлом:

- `Laba2.exe` — графическое приложение (18 МБ).
- `Laba2Scan.exe` — консольный анализатор (16 МБ).

Оба файла имеют формат PE32+ и слинкованы статически: `-static`,
`-static-libgcc`, `-static-libstdc++`. Сторонние DLL ставить не нужно,
программы запускаются на любом 64-разрядном компьютере с Windows 10 и
новее. Единственные внешние зависимости — системная `KERNEL32.dll` и
компоненты универсальной среды выполнения Windows (`api-ms-win-crt-*.dll`),
которые входят в состав ОС.

## Пересборка

Нужен `mingw-w64`:

```
brew install mingw-w64
```

Затем из каталога `laba2`:

```
cmake -S . -B build-win -G Ninja \
      -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-mingw-w64-x86_64.cmake \
      -DCMAKE_BUILD_TYPE=Release
cmake --build build-win
```

## Проверка

Тесты запускаются через Wine, который прописан в файле настроек как
`CMAKE_CROSSCOMPILING_EMULATOR`:

```
ctest --test-dir build-win --output-on-failure
```

Все семь проверок проходят на Windows x86_64.

## Особенности Windows

- Консольный анализатор получает аргументы командной строки через
  `CommandLineToArgvW`. Без этого кириллические пути вроде
  `task/Для проверки Lab2` не находятся, потому что `argv` в MinGW
  приходит не в UTF-8.
- Кодировка консоли переключается на UTF-8 через `SetConsoleOutputCP`,
  иначе русский текст выводится нечитаемо.
- `laba2_core` не зависит от FLTK: все метаданные извлекаются без
  участия графической библиотеки.
