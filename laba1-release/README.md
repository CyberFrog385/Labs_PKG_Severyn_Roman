# Сборка под Windows (лабораторная работа 1, вариант 9)

Скрипт `build_release.bat` собирает приложение ItteC в режиме Release и
раскладывает в эту папку (`laba1-release`) исполняемый файл `ItteC.exe`,
библиотеки Qt, плагины (`platforms`, `imageformats`, `styles`, `iconengines`),
переводы (`translations`) и MinGW-библиотеки — структура такая же, как в
примере принятой лабораторной.

## Требования

- Qt for Windows (MinGW) — например Qt 5.15.2 (MinGW 8.1.0 32-bit) или Qt 6 MinGW,
  установленный через Qt Online Installer.
- `qmake`, `mingw32-make` и `windeployqt` доступны из командной строки.

## Как запустить

1. Откройте командную строку Qt для нужного тулчейна
   (например «Qt 5.15.2 (MinGW 8.1.0 32-bit)» — в ней уже настроен PATH).
2. Выполните:

   ```
   build_release.bat
   ```

3. В папке `laba1-release` появятся `ItteC.exe` и всё необходимое для запуска
   на Windows без установки Qt.

## Имя разработчика

В свойствах `ItteC.exe` (правой кнопкой → Свойства → Подробно) поле «Компания»
содержит значение **Roman Severyn**. Эта информация берётся из файла ресурсов
`lab1_code/ItteC.rc`, подключённого в `lab1_code/ItteC.pro` (блок `win32`),
и отображается также в списке установленных приложений.

Надпись «Проверенный издатель» в окне безопасности Windows достигается только
подписью сборки сертификатом — для лабораторной работы это не требуется.
